# Ótica Ventara — Site

Site institucional e e-commerce da Ótica Ventara, ótica localizada no interior de São Paulo.

## Estrutura
- `index.html` — página principal
- `css/style.css` — estilos
- `js/products.js` — catálogo de produtos
- `js/main.js` — carrinho, filtros, modal, formulário

## Como rodar localmente
Abra `index.html` no navegador ou sirva com qualquer servidor estático:

```bash
npx serve .
```

## Deploy
Compatível com GitHub Pages. Ative em Settings → Pages → Branch `main` / root.
